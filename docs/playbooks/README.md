# Playbooks

## Concepts
* [JupyterLab UI 日本語化手順書](./localization.md) (`Playbook`) - 公式言語パック（jupyterlab-language-pack-ja-JP）を導入してメニューやツールバーを日本語化する手順。
* [Electron メニュー・アイコンカスタマイズガイド](./menu-and-icon-guide.md) (`Playbook`) - electron-jupyter-sandbox におけるアプリケーションメニュー、コンテキストメニュー、トレイアイコン、およびパッケージング用各種OSアイコン設定のベストプラクティス。
* [日本語データ可視化＆ドキュメント操作 実践コードレシピ集](./japanese-data-visualization.md) (`Playbook`) - 超軽量 Noto Sans JP サブセットと SVG ネイティブ描画を活用したグラフ描画・Excel・PDF 帳票処理の実践コード集。
* [完全オフライン Wheel 追加手順書](./offline-wheels.md) (`Playbook`) - 閉空間環境で利用するPythonパッケージ（.whl）を事前ダウンロードしてJupyterLiteに同梱する手順。
* [Electron パッケージング手順書](./packaging-guide.md) (`Playbook`) - Linux (AppImage), Windows (exe), macOS (dmg) 向けの配布用バイナリ生成手順。
* [OSS配布における信頼性確保 & リリースガイド](./release-trust-guide.md) (`Playbook`) - 高額な商用コード署名証明書を購入せずに、信頼性を担保する3大アプローチ、CI自動化フロー、およびSmartScreen対応手順。
