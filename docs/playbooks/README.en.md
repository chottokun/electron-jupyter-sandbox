# Playbooks

## Concepts
* [JupyterLab UI Localization Guide](./localization.md) (`Playbook`) - Steps to introduce official language packs (jupyterlab-language-pack-ja-JP) for localizing menus and toolbars.
* [Electron Menu & Icon Customization Guide](./menu-and-icon-guide.md) (`Playbook`) - Best practices for configuring application menus, context menus, tray icons, and OS target icons.
* [Japanese Data Visualization & Document Manipulation Code Recipes](./japanese-data-visualization.md) (`Playbook`) - Practical code recipes for plotting, Excel processing, and PDF generation using Noto Sans JP subsets and native SVG rendering.
* [Fully Offline Wheel Addition Guide](./offline-wheels.md) (`Playbook`) - Procedure for downloading Python wheels (.whl) in advance to bundle into JupyterLite for offline environments.
* [Electron Packaging Guide](./packaging-guide.md) (`Playbook`) - Steps to generate distribution binaries for Linux (AppImage), Windows (exe/zip), and macOS (dmg).
* [OSS Trust Assurance & Release Guide](./release-trust-guide.md) (`Playbook`) - Strategies to build user trust without commercial code signing certificates, CI automation workflows, and SmartScreen handling.
