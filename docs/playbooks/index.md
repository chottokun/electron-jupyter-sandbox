# Playbooks

## Concepts
* [JupyterLab UI 日本語化手順書](/playbooks/localization.md) (`Playbook`) - 公式言語パック（jupyterlab-language-pack-ja-JP）を導入してメニューやツールバーを日本語化する手順。
* [完全オフライン Wheel 追加手順書](/playbooks/offline-wheels.md) (`Playbook`) - 閉空間環境で利用するPythonパッケージ（.whl）を事前ダウンロードしてJupyterLiteに同梱する手順。
* [Electron パッケージング手順書](/playbooks/packaging-guide.md) (`Playbook`) - Linux (AppImage), Windows (exe), macOS (dmg) 向けの配布用バイナリ生成手順。
* [Electron メニュー・アイコンカスタマイズガイド](/playbooks/menu-and-icon-guide.md) (`Playbook`) - アプリケーションメニュー、コンテキストメニュー、および各OS向けアイコン設定の手順とベストプラクティス。
* [OSS配布における信頼性確保 & リリースガイド](/playbooks/release-trust-guide.md) (`Playbook`) - 高額な商用コード署名証明書を購入せずに信頼性を担保するアプローチ、CI自動化フロー、SmartScreen対応手順。
